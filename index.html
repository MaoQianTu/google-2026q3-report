财报好在哪（3 条）

  • 营收 $127.577B，+24.65% YoY（不变汇率亦 +25%），近四年最好增速之一。
  • Google Cloud $30.709B（+102.6%），营业利润率 36.2%（+12.5pct），五大板块唯一超预期。
  • Cloud backlog 约 $560B（Q2 $514B，+8.9% QoQ）；Gemini App 用户破 10 亿；第一方 API 用量 320 亿 tokens/分钟（一年 4 倍+）。

财报差在哪（3 条）

  • 营业利润 $40.576B vs 预期 $43.19B（−6.1%），近四年首次营收+利润双 miss。
  • FCF −$9.065B（预期 −$2.70B，缺口 3.4 倍），连续第二季为负。
  • Search 增速 19%→17%→12% 三连降；回购 $0 + 发债 $29.0B + ATM 增发 $12.4B。
为何暴跌

收入只 miss 0.5%，股价却跌 11%

市场下调的不是这个季度，而是「搜索还能按 15%+ 增长多久」这一终值假设，以及「轻资产现金牛」这套估值公式。

估值判定
$324.89（10/28 收盘）= 高估（正常化 PE 30.5x / 市值÷营业利润 25.3x）；
$288.71（10/29 盘前）= 合理区间上沿（27.1x / 22.5x）。
SOTP 合理区间 $270–306（中值 $288）。
一句话结论：公司没变差，是它主动从「轻资产印钞机」变成「AI 重资产基础设施商」；市场在为这次身份转换重新定价，不是在为这份财报定价。

会计质量提示：Cloud 36.2% 的利润率是在不承担模型训练成本前提下算出的——若把同比多烧的 $3.19B 按营收权重分摊，Cloud 营业利润降至约 $7.9B、利润率约 25–26%。这是本季最被忽视的会计质量问题。

财报后为何暴跌：五维并列归因

★★★★★
维度（不同切面）来源结论
宏观 vs 个股卡萨丁公司基本面 ~80% / 宏观 ~20%，其中宏观直接贡献仅 ~2pct（10Y 4.99%→5.05%）。最强反证：同一晚发财报的 MSFT 股价上涨
行业 vs 公司索拉卡行业性 ~30% / 公司自身 ~70%。云行业 +43%（八年最高）、广告大盘仍增长，行业没坏；坏的是搜索变现效率
估值杀 vs 盈利杀黑默丁格机械口径 100% 估值杀（TTM 营业利润 +29.9%，E 未降，倍数 25.3x→22.5x）；经济口径 ~63% 估值杀 + ~37% 盈利预期杀
资金结构斯维因趋势/量化资金在流动性真空中抛售（估 40–50%），长线机构未出逃；空头仅占流通股 0.74%；Q2 四大机构净买入 5,800 万股
一二级定价提莫定价机制从叙事切到 ROI：OpenAI 自降 $150B、Anthropic 遭压价、CoreWeave 财报后均值 −17%，−11% 是切换的正常幅度，不是错杀
⚠️ 五个维度是五个不同切面，分母不同，绝不可相加（不存在 80% 基本面 + 30% 行业 这种算法）。
一句话：不是这个季度赚少了，而是未来三年的赚钱方式和现金流结构被重新定价了——这是估值杀，但杀得有道理。

如何客观看待这家优秀的企业

★★★★
  • 护城河：基础设施层在扩大，应用变现层在收窄。扩大的是 TPU（第 7 代 Ironwood + 首次对外供货 Oracle）、Gemini（10 亿用户、320 亿 tokens/分钟）、backlog $560B；收窄的是搜索广告变现率（查询量五年最高 vs 收入增速三年最低）。
  • 性质：不是被颠覆，是自我蚕食 + 主动换身份。它选择把现金牛变成 AI 重资产基础设施商，估值框架随之从 P/FCF 25x 切换为 EV/EBITDA 15–18x，中枢下移是结构性的，不是情绪性的。
  • 适合什么样的投资者：能承受 1–2 个季度负 FCF、看好 TPU/云长期兑现、且不需要现金回报的长线投资者；不适合依赖分红回购或短期动量交易的资金。当前价位无安全边际也无泡沫，$285 附近是合理中枢。
